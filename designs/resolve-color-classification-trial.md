## 证据与处理边界

1. 核对 XML/源文件方向和色彩输入，显式 sidecar 优先于 root fallback。不能沿用旧 Group 名推断 D-Log/D-Log M，也不对 Rec.709 重复套 Log LUT。
2. 先验证新 timeline local versions、空白 graph 和技术变换，再大量导入；不得跨素材复制含 Gyroflow 路径、限定器、美肤、降噪的完整修复链。
3. 分类结合技术还原后的多位置画面、源方向和已有视觉分析；字幕/对白提到清晨、夜景等不是画面证据。暗噪、频闪需连续帧复核，未检查区域不能标为无问题。
4. 技术输入与九类解耦；使用 clip 级技术 LUT、基础校正和九个空白 Group。安装版公开 API 没有节点插入接口，冷启动实测为一个空白节点，因此本次采用同一 clip node 的 CDL + LUT，并用两个 local versions 分开技术还原与基础试调。先通过原生动态输出校准其处理顺序和幅度，不复制旧多节点链来凑节点数量。
5. 每条保留技术还原与基础试调两个 local versions。类别决定校正方向，参数由素材证据决定；不确定者只保留技术还原并列出原因。
6. 选取约 20 个跨类别/相机样本校准，动态原生导出验证后再全量应用。仍需全量覆盖、异常清单、原时间线保全验证。
7. 本轮不自动执行美肤、Gyroflow、降噪或 Deflicker 参数调节；识别这些需求与验证自动修复分别报告。只用已验证的 Resolve LUT/CDL/版本/Group 能力。
