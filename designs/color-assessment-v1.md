## 场景规则

无新增模型请求。对已有中文/英文描述采用保守、可测试的明确陈述规则，保留命中的原文与窗口，含否定、推测、矛盾或覆盖不足时复核。此规则只读取出镜讲述、视角、室内外、日夜及变化语义；描述中的“过曝/噪点/偏色”等文字不能产生技术阳性。

- 竖屏优先且排他，方向只取 Color 对待调原片的独立 probe（编码尺寸、旋转元数据和有效显示尺寸）。仅原片内部字段矛盾或方向未知时复核；不得与 Analyze 所选 target 的尺寸比较后判冲突。目标可以经过旋转、裁切或重新编码。90° / -90° 是 Color 的技术信息，用于竖屏分类和标准模板选择，不是模型判断或重跑 Analyze 的理由。分类本身不旋转素材。
- 人物出镜讲述与语音证据联合成立即可，包含别人拍摄的讲述者、车内口播。`talking-head` 缺描述支持或描述冲突不能无条件通过；`drive` 不能覆盖明确人物讲述。
- 白天车内行车（当前显示名“白天前挡行车”）要求 drive + 向前道路/车头/前挡视角，不因 drive alone 命中，也不需要证明前挡偏色；车内人物讲述按人物口播优先规则处理。
- 日照计算使用已校正 capturedAt，不再次应用 root offset；按 GPS 代表点计算开始/中间/结束太阳高度、当地太阳日的日出日落 UTC 时间。太阳几何不能独自把室内、车库、隧道归成夜景。跨日照阶段/室内外变化保留已有区间并复核，不编造转换时刻。
- NOAA 近似太阳算法；日出/日落太阳中心 -0.833°，民用曙暮光 -6°。+6° 以内低太阳作为项目晨昏候选，不冒充天文定义。地形、天气和代表 GPS 不提供真实照度，画面描述矛盾时复核。

## 独立技术检测

全片概览与噪声连续帧采样独立于视觉分析。只读真实待调 raw；显示判断使用配置的 LOG 显示 LUT，Rec.709 bypass。该显示 LUT 是诊断视图，不是 Resolve RCM 的逐像素等价物，不写到调色节点。输入或变换不明确则对应指标未知。

- 过曝概览以 1 fps 覆盖整个时长。显示亮度中位数 >= 0.74、亮度 >= 0.7 占比 >= 55%、中下部中位数 >= 0.65 / P10 >= 0.35、底部中位数 >= 0.6、至少 10/16 网格均值 >= 0.65 联合触发整体偏亮；既有大面积白化也是候选。排除顶部亮带主导，再要求连续至少 3 秒（更短素材须覆盖全长），保留实际命中区间。均匀亮色、白墙/雪雾描述等歧义复核。这些均为工程阈值，不是物理曝光正确性的绝对证明；常规天空、太阳、灯具、局部高光与短暂闪白不单独触发。
- 源编码与显示视图分别测量。YUV 的白端平台掩模在原始 Y 码值上、缩放/RGB 转换之前生成，保留位深与 full/limited 范围，避免把可恢复 superwhite 当成源裁切；RGB 原片检查编码顶端。VideoToolbox 半平面输出先显式转换为平面格式，避免 FFmpeg extractplanes 格式协商崩溃。显示整体偏亮可以进入过曝主类，但不能据此宣称源细节不可恢复。LOG 编码满量程不等于传感器剪切点，本阶段不硬编码各机型 sensor clipping；LOG 的 sourceClipping 保持 unknown。Rec.709 的源白端平台及 superwhite 区分写入 sourceClipping，不能作为曝光类别的联合门槛。
- 噪声使用分布于全片的连续帧、多个原分辨率局部块，不对缩小预览估噪。时间残差用稳健统计估计；过滤运动、亮度漂移和空间纹理，并要求多个空间位置有效。同时记录源信号和显示视图噪声。明显噪点独立成类，不要求极暗；显示时间 sigma >= 0.004 且源信号 sigma >= 0.00075，并保留有效块/位置、运动排除和跨采样持续条件。仅暗、细纹理、可用静态区域不足均不能推定噪点。固定图样噪声、严重压缩、强运动等无法确认的情况明确局限。
- 首版阈值版本化，属保守工程初值；合成正负样本与真实样本验证，不宣称已完成全部设备标定。检测只分类/标记，不设置曝光、WB、降噪参数。
- 逆光/大光比读取独立 1 fps 的统一亮暗区域测量，连贯暗部至少 10%、区域均值差至少 0.5，不再按亮区面积分路。要求至少一段连续 3 秒（更短片须覆盖全长）、实际命中区间并集超过 50% 时长；少数或各半时保留基础场景主类及局部区间，间隙不桥接。夜景通过既有描述与日照上下文硬排除；晨昏可参与，冲突/未知不默认为非夜景。完整阈值与限制见 `color-high-contrast-v1.md`。
- 偏色幅度与频闪仍未检测，属于本轮范围之外；未检测不能写成阴性，也不能当作白天车内行车分类的阻塞条件。

## 冲突、分组及正式入口

优先级：竖屏 → 人物口播 → 大面积过曝 → 明显噪点 → 大光比（夜景硬排除） → 清晨/黄昏 → 普通夜景 → 白天前挡行车 → 常规日景。每个命中需要自己的证据。已明确的竖屏/人物可带其它待检测问题；其它分类有专项不确定性时保留候选及复核理由。

复核是 `status`，`category` 可为空，不产生第十个 Resolve Group。新待复核项仍可准备 RCM 和标准五节点，但保持无组；快照中的 Ungrouped 只是无组视图，用 `nativeGroup=false` 标记，Console 与服务端统计不计入真实 Group 数量。已有分组降为不确定时阻塞搬组，保留原组调色；不静默移除已有 Group grade。RCM/五节点流程必须按 colorManagementPolicy 判断，不能用有无 sceneCategory 决定技术还原。正式 prepare 先校验整个请求范围的 Analyze/原片前置，再计算/复用检测，避免解码之后才因其它素材缺报告失败；导出只核对测量/分类签名。没有修改过的旧工程不自动迁移。

描述规则同时区分“摄像机位于车内”和“画面主体是室内”：drive + 明确向前/前挡视角不因为描述提到车内就被当成室内场景。仅少量窗口出现讲述者、但整片 summary 不支持统一出镜讲述时进入复核。
