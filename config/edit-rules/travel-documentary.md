# 旅行纪录片剪辑规则

## 前置信息分析整合

1. 分析Pharos行程
2. 结合Pharos行程，以及素材分析和GPS信息，补全未记录的推测事件
3. 在每个单点事件之间如果有行车视频，结合GPS，分析出行车路径摘要
4. 结合以上信息，生成完整的行程和事件表，供人工审查迭代，直到通过
5. 根据行程和事件表，结合素材分析结果，生成`完整素材档案`，供下游使用

## 初版剪辑框架

1. 读取理解现有行程信息和素材档案
2. 生成剪辑框架文本，按天、重点时间、行车、航拍和关键事件组织
3. 素材必须大致按照时间顺序排列，但是行车部分有额外规则
4. 行车部分，由于包含口播部分/第一视角行车/无人机跟车，所以可能需要按照节奏，进行更合理的编排
5. LLM生成文本稿件，交由人工审查，这个过程可能是多轮的、交互式的

## 交互式粗剪

1. 根据剪辑框架的定稿，进入素材召回阶段
2. 这一个阶段同时要确定那些素材要静音、加速等，由人工简短确认
3. 根据最终结论，在达芬奇剪辑工程内，生成对应的时间线
4. 人工和LLM针对时间线，交互式修改，直到阶段性定稿，人工确认进入下个阶段

## 收尾

1. 根据粗剪定稿，生成源语音字幕
2. 对于没有语音的段落，根据视频内容，生成旁白稿，需要参考指定`风格分析`结果，最终由人审查
3. 审查结束后，生成完整字幕，并应用到达芬奇时间线上
