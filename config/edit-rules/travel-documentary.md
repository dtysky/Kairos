# 旅行纪录片剪辑规则

## 初版剪辑框架

1. 读取理解现有的编年史，生成剪辑框架文本，按天、重点时间、行车、航拍和关键事件组织。使用`SubAgent`，切分按照天，但不是每天一个，而是按照80个事件左右为阈值拆分几天是一个包！
2. 素材必须大致按照时间顺序排列，但是行车部分有额外规则：
  1. 行车部分，由于包含口播部分/第一视角行车/无人机跟车，所以可能需要按照节奏，进行更合理的编排，比如如果同时有无人机跟车和非口播行车素材在一个时间窗口重复，优先使用无人机跟车素材
  2. 行车之外，同一个事件中不同类型的视频，航拍要聚在一起排列插入在普通视频之中，照片要聚在一起排列在最后（按照每张1s）
3. LLM生成文本稿件，交由人工审查，这个过程可能是多轮的、交互式的

## 交互式粗剪

1. 根据剪辑框架的定稿，进入素材召回阶段，使用`SubAgent`，切分按照天数粒度，但不是每天一个，而是按照2000个素材左右为阈值拆分几天是一个包！
2. 这一个阶段同时要确定那些素材要静音、加速等，由人工简短确认
3. 根据最终结论，在达芬奇剪辑工程内，生成对应的时间线
4. 人工和LLM针对时间线，交互式修改，直到阶段性定稿，人工确认进入下个阶段

## 收尾

1. 根据粗剪定稿，生成源语音字幕
2. 对于没有语音的段落，根据视频内容，生成旁白稿，需要参考指定`风格分析`结果，最终由人审查
3. 审查结束后，生成完整字幕，并应用到达芬奇时间线上
